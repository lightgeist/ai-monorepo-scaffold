# Actual terminal evidence

`assets/atlascode-terminal.png` is a captured AtlasCode PTY frame, interpreted by a terminal emulator. It is not a UI mockup or a generated image. The release evidence includes additional frames, raw ANSI output and interaction records.

The coding journey uses a deliberately broken, tiny clamp project. The live assistant reads the actual provider requests, requests real file reads, runs the existing tests, fixes only the implementation, reruns the same tests, and reports the result. The transcript records the distinction between live assistant responses and deterministic synthetic-provider tests.

This demonstrates that specific runtime journey. It is not a claim that every hosted account, external plugin, provider model or arbitrary project was tested.
