# Release audit

The authoritative audit is shipped in the release's `evidence/` directory. It includes the pinned baseline, current tests, source/package/runtime brand scans, immutable-vendor checks, terminal frames, clean-install results and live-relay evidence.

A passing unit suite does not qualify unexercised hosted services or other operating systems. Each check records PASS, FAIL, SKIPPED or NOT QUALIFIED with evidence. Original upstream audit claims are not recycled as AtlasCode acceptance results.
