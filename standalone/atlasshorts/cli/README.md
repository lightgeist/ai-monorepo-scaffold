# AtlasShorts CLI

Install `python -m pip install ./cli` from the release root, or install the supplied wheel.
No public package-registry publication is implied. `atlasshorts --help` lists commands.
`ATLASSHORTS_API_URL` defaults to localhost:8000. Configure provider keys on the backend
or use GEMINI_API_KEY and UPLOAD_POST_API_KEY as needed. See START-HERE.md.
